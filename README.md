# 📝 ToDo App

A simple and modern To-Do application developed with **SwiftUI**.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 💾 Persistent storage using UserDefaults

## 🛠️ Technologies

- Swift
- SwiftUI
- MVVM
- UserDefaults
